# Инструкции агенту

## Назначение

Это личное рабочее пространство и память пользователя.
В Git пространства хранятся только метаданные, а не сами проекты.
Общайся по-русски, если пользователь не попросил иначе.

## В начале сессии

1. Прочитай `memory/profile.md` и `memory/context.md`.
2. Для задачи по направлению прочитай соответствующий файл в `areas/`.
3. Для задачи по проекту прочитай его карточку в `projects/`.
4. Перед изменениями файлов проекта изучи его собственные инструкции.

## Размещение файлов

- В `projects/` размещай только Markdown-карточки по `templates/project.md`.
- Исходники, медиа, зависимости, сборки и рабочие материалы размещай в
  `workspace/` либо за пределами пространства.
- Не перемещай существующие проекты без запроса пользователя.
- Не обходи `.gitignore` через `git add -f`.
- Перед коммитом проверь, что в изменениях только метаданные.
- Не публикуй репозиторий и не отправляй его на удалённый сервер без просьбы.

## Ведение памяти

- Сохраняй только явно сообщённые пользователем или проверенные сведения.
- Не выдавай догадки за факты. Неизвестное оставляй незаполненным.
- Устойчивые сведения и предпочтения записывай в `memory/profile.md`.
- Текущий фокус и следующие шаги записывай в `memory/context.md`.
- Цели, статус, пути, решения и контекст проекта записывай в его карточке.
- Обновляй память после существенных изменений; не копируй всю переписку.
- Датируй существенные записи, исправляй устаревшее, избегай дублирования.
- Не записывай секреты и чувствительные личные сведения.
