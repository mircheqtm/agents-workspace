# О пользователе

Обновлено: 2026-10-21.

## Подтверждено пользователем

- Хочет единое агентное пространство, из которого будет запускать Codex.
- Хочет сохранять сведения о себе, работе и проектах в Git.
- В репозитории пространства должны храниться только метаданные.
- Сами проекты должны быть исключены из Git этого пространства.
- Первые направления работы: видео и программирование.
- Предпочитает графическое приложение для работы с Codex вместо терминала.

## Пока не указано

- Имя и предпочтительное обращение.
- Конкретные проекты и цели.
- Инструменты для видео и стек разработки.
