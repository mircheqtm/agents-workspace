# Моё агентное пространство

Личная память, планы и контекст работы по направлениям «Видео» и «Программирование».
В этом Git-репозитории хранятся только метаданные. Сами проекты и материалы
находятся в игнорируемой папке `workspace/` либо за пределами пространства.

## Структура

- `AGENTS.md` — инструкции агенту и правила ведения памяти.
- `memory/profile.md` — подтверждённые сведения о пользователе и предпочтения.
- `memory/context.md` — текущий фокус и следующие шаги.
- `areas/video.md` — цели, инструменты и проекты направления «Видео».
- `areas/programming.md` — цели, стек и проекты направления «Программирование».
- `projects/` — Markdown-карточки проектов, без исходников и материалов.
- `templates/project.md` — шаблон карточки проекта.
- `workspace/video/` — локальные видеопроекты и материалы.
- `workspace/programming/` — локальные проекты разработки.

## Начало работы

```bash
cd ~/agent-workspace
codex
```

Для нового проекта скопируй `templates/project.md` в `projects/<название>.md`.
Укажи путь к самому проекту: например, `workspace/programming/<название>/`
или существующий внешний каталог. У проекта может быть собственный Git-репозиторий.
Перемещать существующие проекты сюда необязательно.

После существенной работы обновляем карточку проекта и текущий контекст.
Устойчивые факты и предпочтения сохраняем в профиле.

## Что попадает в Git

`.gitignore` разрешает только служебные файлы в корне и Markdown-файлы
непосредственно в `memory/`, `areas/`, `projects/`, `templates/`.
Все остальные пути по умолчанию игнорируются, включая `workspace/` целиком.
Каталоги метаданных предназначены только для заметок, даже если исходники
проекта тоже написаны в Markdown.

Перед коммитом проверяй `git status` и `git diff --cached`.
Не сохраняй пароли, токены и другие секреты. Репозиторий пока только локальный.
